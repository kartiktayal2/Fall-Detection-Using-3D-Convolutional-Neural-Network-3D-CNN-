# Fall-Detection-Using-3D-Convolutional-Neural-Network-3D-CNN-
This experiment implements a 3D Convolutional Neural Network (3D CNN) to detect falls from video sequences using the UR Fall Detection dataset. Video frames are preprocessed and stacked as 3D tensors, and the model is trained to classify fall and non-fall activities using accuracy, recall, F1-score, and AUROC for evaluation.
